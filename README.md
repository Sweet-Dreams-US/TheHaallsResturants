# Don Hall's Restaurants — Demo Site

A full demo site for [Don Hall's Restaurants](https://www.donhalls.com/) — Fort Wayne's family-run dining group, serving since 1946. Built as a creative concept piece showcasing all ten restaurant concepts, the Hall family story, online ordering, gift cards, and more.

**Live demo:** https://sweet-dreams-us.github.io/TheHaallsResturants/

## Stack

- **Vite + React 18 + TypeScript**
- **Tailwind CSS** with custom heritage palette (cranberry, gold, cream, ink)
- **Framer Motion** for page transitions, scroll parallax, and micro-interactions
- **React Router** (HashRouter for GH Pages compatibility)
- **localStorage** cart persistence
- All hero imagery generated with **Higgsfield** (Soul Location model)

## What's in here

- **Home** — Cinematic hero, restaurant grid, Hall family story teaser, press quotes
- **The Story** — Full timeline 1918 → 2026, milestones, family quotes
- **Restaurants** — Index of all 10 concepts + dedicated detail page each
  - The Gas House, The Tavern, The Deck, Takaoka of Japan, The Factory,
    Hall's Commissary, Hall's Hollywood, Hall's State Street, Tap Haus, Triangle Park
- **Online Ordering** — Per-restaurant menu → cart → checkout → confirmation flow
- **Specials** — Daily specials and upcoming events
- **Gift Cards** — Live gift-card preview with amount picker
- **Jobs** — Filtered openings by restaurant
- **Contact** — Direct phone lines + topical inquiry form

## Develop locally

```bash
npm install
npm run dev
```

Open http://localhost:5173.

## Build & preview

```bash
npm run build
npm run preview
```

## Deploy

Pushing to `main` triggers `.github/workflows/deploy.yml` which builds and publishes to GitHub Pages.
